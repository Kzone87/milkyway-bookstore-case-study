WHAT I WOULD CHANGE TODAY

과거 구현을 현재 기준으로 다시 평가

01

계층 분리

JSP/JDBC 혼합 대신 Controller–Service–Repository와 명시적 DTO 경계를 둡니다.

02

트랜잭션

장바구니→위시리스트, 구매→취소 같은 다중 SQL 상태 전이를 하나의 transaction으로 묶습니다.

03

인증 현대화

직접 SHA-256을 조합하지 않고 Argon2id/bcrypt 계열과 검증된 보안 프레임워크를 사용합니다.

04

Secret 관리

API/DB credential을 코드가 아닌 환경변수 또는 secret manager에 둡니다.

05

상태 모델

문자열 상태값 대신 enum/state model과 validation을 사용합니다.

06

자동 검증

로그인, 주문, 취소, 검색 흐름을 integration test와 PR CI로 검증합니다.

MAINTENANCE
